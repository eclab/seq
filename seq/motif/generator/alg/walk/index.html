Random Walks

This is a collection of methods for doing melodies in the form of random walks. You can pick a method for selecting the next pitch in your random walk (relative to the current one), and a method for selecting the length of the next note. At present there are two methods:

  • 1/f (or Pink) Noise. This method generates random noise using pink noise, which has a much higher probability for small events (small changes in pitch and preference for shorter notes over longer ones). You can stretch the size of typical events by adjusting the weight.

  • Binomial Noise. This method generates random events by iteratively flipping a coin until it comes up heads, then returning how many flips that was. You an stipulate the probability by adjusting the weight.

Adjusting Note Pitch

You first need to specify how the Random Walk chooses note pitches.
  • Scale. This allows you to lock the pitch of notes to specific scales. Note that some scales (or in many cases chords) have fewer total notes per octave than others: as a result the random walk will be more spread out for them; you may need to adjust the pitch weight accordingly.

  • Method. Here you specify which of the above methods is used in choosing the next note to wander to.

  • Start Pitch. The default initial note in the melody (before you transpose with transpose), prior to applying the start weight to (possibly) randomize it.

  • Start Weight. The Method will, starting with the start pitch, wander one step with the start weight to arrive at the first note to play. If you'd like to always start with your chose start pitch, rather than some random deviation of it, then set the start weight to 0.

  • Weight. Each time the Method needs to pick a new note, its pitch will be chosen by wandering one step from the previous note's pitch, using the weight. Make the weight larger to deviate more significantly.

  • Increment Probability. One common deviation from the previous note pitch is no deviation at all. You probably don't want that very often. The increment probability stipulates how often the Random Walk will add one pitch step to the final deviation (thus making it impossible to deviate by zero).

  • Tether. This is the probability that at any given time the Random Walk will choose to gravitate back to its starting pitch rather than walk randomly. You can use this to rope in the Random Walk to keep it from heading too far afield, particularly if you have a high Increment Probability.

Adjusting Note Length

Note length is pretty crude right now: it's just randomly selected under the distribution specified by the chosen Method.
  • Method. Here you specify which of the above methods is used in choosing the note length. Shorter notes are more likely.

  • Weight. Each time the method needs to pick a new note, its length will be chosen with random nose using the given weight. Make the weight larger to select longer notes more often.

  • Gate. The percentage of the total note length spent playing the note. At present this is a fixed value rather than randomly chosen; but you can attach it to a random parameter.

Rests

Sometimes you don't want to play a note.
  • Rest Probability. The probability that the Random Walk will play a rest rather than a note.

General Overall parameters.
  • Transpose. How to transpose the final pitch.

  • Volume. The volume of each note.

  • Rate. How fast Random Walk selects new notes.

Authorship

Numerous authors have suggested random walk distributions, particularly for pitches, and especially for 1/f or Pink noise distributions.
